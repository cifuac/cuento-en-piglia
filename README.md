# El cuento en Piglia

Presentación interactiva de 20 láminas sobre las tesis de Ricardo Piglia sobre el cuento («Tesis sobre el cuento» y «Nuevas tesis sobre el cuento», en *Formas breves*, 2000): las dos historias, la historia secreta y el final.

**Ver la presentación:** https://cifuac.github.io/cuento-en-piglia/

Teclas: flechas para avanzar, `I` índice de láminas, `S` historia secreta, `F` pantalla completa.
